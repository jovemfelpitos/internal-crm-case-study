# Security and Confidentiality

This repository is a public technical case study and does not include the original proprietary source code.

## What Is Not Included

- No original application source code.
- No database files.
- No real spreadsheets.
- No credentials.
- No environment files.
- No logs.
- No production URLs.
- No customer names.
- No CPFs or personal identifiers.
- No phone numbers.
- No internal e-mails.
- No confidential business rules.

## Images and Diagrams

All images and diagrams in this repository are illustrative. Screenshots use fictitious names and masked identifiers only.

## Publication Approach

The goal of this repository is to demonstrate engineering decisions, system architecture, technical trade-offs and product impact without exposing corporate intellectual property.

## Reporting Concerns

If any sensitive information is found in this repository, remove it immediately and rotate any potentially affected credentials outside of this repository.
