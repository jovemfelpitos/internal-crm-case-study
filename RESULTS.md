# Results

## Operational Improvements

The CRM improved the operation by replacing spreadsheet-based tracking with a structured system. Users gained a focused dashboard, customer profile pages and controlled fields for daily work.

## Better Data Control

Duplicate detection by normalized identifier reduced repeated customer records. Data imported from Excel became persistent and queryable in a relational database.

## Improved Accountability

Audit logs record relevant business and administrative events, making it possible to understand who changed what and when.

## Safer Access Management

The system separates access by user role, team and granular permissions. Operators see only their own assigned customers, supervisors see their teams and admins manage the full system.

## More Flexible Administration

Admins can manage users, teams, role profiles and operational labels without modifying source code.

## Better User Experience

The dashboard and customer profile page make the system feel like a CRM instead of a spreadsheet. Filters, pagination, color-coded labels and dark mode improve daily usability.

## Production Readiness

The project includes security hardening, HTTPS-oriented configuration, backup strategy and an operational path for running the application on a VPS.

## Engineering Outcomes

The project demonstrates:

- full-stack delivery;
- backend business rule design;
- role and permission modeling;
- Excel data ingestion;
- audit logging;
- production deployment thinking;
- secure-public documentation practices.
